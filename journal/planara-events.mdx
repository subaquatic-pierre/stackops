## Overview

**Planara** is an all-in-one event management SaaS product built by CODATIVITY for event organizers in Dubai and Saudi Arabia. This project is the **public marketing website and blog** — a visually rich landing page that showcases the product while a separate application handles the core event management functionality.

The site is a single Next.js application with no backend or database of its own. All dynamic content (blog posts and SEO metadata) is fetched from an external Strapi CMS, while landing page content is defined in static data files. The design features Mantine UI components, styled-components theming, and an extensive animation layer.

---

## Key Features

- **12-section landing page:** Comprehensive product showcase from hero to testimonials in a single scrollable experience
- **Headless CMS blog:** Blog updates from Strapi propagate instantly via ISR — no redeploy needed
- **Dual theme system:** Light and dark modes with color variants for accessibility
- **Rich animation layer:** Particle effects, parallax scrolling, count-up statistics, reveal animations — all tastefully composed
- **SEO-optimized:** Dynamic sitemap, robots.txt, JSON-LD structured data, and per-page Open Graph metadata from Strapi
- **Middle East compliance:** DTCM API integration, Saudi Arabia cloud deployment, Arabic support
- **45 reusable UI components:** A component library for rapid feature development

---

## Architecture

A **single-service frontend** that reads from an external CMS:

| Service | Role |
|---------|------|
| **www** (Next.js) | Public marketing site + blog |
| **Strapi CMS** (external) | Blog content, SEO metadata, global settings |

No backend or database in this repository. The Next.js frontend is purely a presentation layer — SSG with ISR ensures blog updates from Strapi propagate within 10 seconds without a redeploy.

---

## Frontend — Next.js Landing Page

Built with Next.js 13 Pages Router, styled-components for theming, and Mantine v6 for the component library. The site features extensive animations: `animate.css`, `react-awesome-reveal`, `react-parallax` for scroll effects, `react-countup` for animated statistics, and `react-tsparticles` for interactive particle backgrounds.

### Homepage Sections (12 total)

1. **Banner** — Hero with animated tagline and CTA
2. **Dashboard screenshot** — Product UI preview
3. **Analytics Tool** — Visual data and reporting showcase
4. **How It Works** — Step-by-step product walkthrough
5. **Pricing** — Tiered pricing cards
6. **FAQ** — Expandable accordion
7. **Call to Action** — Secondary conversion section
8. **Client logos** — Trusted-by section
9. **Integrations** — Technology partner logos
10. **Testimonials** — Client quotes with avatars
11. **Community** — Social proof and community stats

### Blog

Blog content is fetched from a Strapi CMS at `api.codativity.codaweb.co`. Posts are displayed with 9 items per page and client-side pagination. Each post detail page pulls SEO metadata (title, description, Open Graph images, Twitter cards, JSON-LD structured data) directly from Strapi's SEO collection — ensuring every blog post is search-engine optimized without manual meta tag configuration.

---

## CMS Integration

The Strapi CMS (hosted separately on CODATIVITY's infrastructure) manages:

- **Blog posts** — Full articles with categories, authors, and tags
- **SEO metadata** — Per-page and per-post SEO configuration
- **Global settings** — Site-wide branding and configuration

Next.js fetches content at build time via SSG and revalidates every 10 seconds through ISR. When a content editor publishes or updates a blog post in Strapi, the change appears on the live site within seconds — no deployment required.
