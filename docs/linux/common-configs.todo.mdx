## Overview

Linux systems store configuration in predictable locations. Knowing where to look reduces troubleshooting time and avoids guesswork during incident response.

## System configuration

| Purpose                 | Path                                     | Notes                                                      |
| ----------------------- | ---------------------------------------- | ---------------------------------------------------------- |
| Hostname                | `/etc/hostname`                          | Static hostname set at boot.                               |
| Network interfaces      | `/etc/network/interfaces`                | Debian-based; RHEL uses `/etc/sysconfig/network-scripts/`. |
| DNS resolver            | `/etc/resolv.conf`                       | Often generated by systemd-resolved or NetworkManager.     |
| Local users             | `/etc/passwd`                            | User account definitions.                                  |
| Local groups            | `/etc/group`                             | Group definitions.                                         |
| Sudoers                 | `/etc/sudoers` and `/etc/sudoers.d/`     | Edited with `visudo`.                                      |
| SSH server              | `/etc/ssh/sshd_config`                   | Requires `sshd` reload after changes.                      |
| System-wide environment | `/etc/environment` and `/etc/profile.d/` | Applied at login.                                          |

## Service configuration

| Purpose       | Path                                                    | Notes                          |
| ------------- | ------------------------------------------------------- | ------------------------------ |
| systemd units | `/etc/systemd/system/` and `/usr/lib/systemd/system/`   | Custom units belong in `/etc`. |
| Log rotation  | `/etc/logrotate.conf` and `/etc/logrotate.d/`           | Per-service rotation rules.    |
| Cron jobs     | `/etc/cron.d/`, `/etc/cron.daily/`, `/etc/cron.weekly/` | System-level scheduled tasks.  |

## Application configuration

- `/etc/<application>/` — system-wide application configs.
- `~/.config/<application>/` — per-user configs on modern distributions.
- `~/.<application>/` — legacy per-user configs.
