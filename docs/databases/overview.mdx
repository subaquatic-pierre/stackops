# Databases

## Overview

Reference material for configuring, managing, and troubleshooting common database systems on Linux. More detailed guides coming soon.

## Quick starts

### PostgreSQL

```bash
# Install
apt install postgresql

# Connect
sudo -u postgres psql

# Create database and user
CREATE DATABASE myapp;
CREATE USER myuser WITH PASSWORD 'secret';
GRANT ALL PRIVILEGES ON DATABASE myapp TO myuser;
```

### MySQL / MariaDB

```bash
# Install
apt install mysql-server

# Connect
mysql -u root -p

# Create database and user
CREATE DATABASE myapp;
CREATE USER 'myuser'@'localhost' IDENTIFIED BY 'secret';
GRANT ALL PRIVILEGES ON myapp.* TO 'myuser'@'localhost';
FLUSH PRIVILEGES;
```

### Redis

```bash
# Install
apt install redis-server

# Connect
redis-cli

# Check status
redis-cli ping
redis-cli info
```

## Common commands

### Backup

```bash
# PostgreSQL
pg_dump myapp > backup.sql
pg_dump -Fc myapp > backup.dump          # compressed custom format

# MySQL
mysqldump myapp > backup.sql
mysqldump --all-databases > all.sql

# Redis
redis-cli SAVE                           # trigger RDB snapshot
cp /var/lib/redis/dump.rdb backup.rdb    # copy RDB file
```

### Restore

```bash
# PostgreSQL
psql myapp < backup.sql
pg_restore -d myapp backup.dump

# MySQL
mysql myapp < backup.sql

# Redis
systemctl stop redis
cp backup.rdb /var/lib/redis/dump.rdb
systemctl start redis
```

## Configuration files

| Database | Config location |
|---|---|
| PostgreSQL | `/etc/postgresql/<version>/main/postgresql.conf` |
| PostgreSQL (client auth) | `/etc/postgresql/<version>/main/pg_hba.conf` |
| MySQL / MariaDB | `/etc/mysql/my.cnf` or `/etc/mysql/mariadb.conf.d/` |
| Redis | `/etc/redis/redis.conf` |
