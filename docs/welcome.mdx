StackOps is a knowledge base for infrastructure, operations, and development workflows. It is organized as a hybrid cookbook and reference manual: goal-oriented playbooks sit next to conceptual deep-dives, all discoverable through search and tags.

## Content types

Documents are categorized by intent, not by hierarchy.

- **Actionable** — goal-oriented playbooks with copy-paste commands. File names follow the pattern `verb-noun-context.mdx`.
- **Reference** — conceptual explanations, architectures, and config locations. File names follow the pattern `noun-context.mdx`.

Use the sidebar to expand a domain, or use the search bar to find a specific tool, command, or concept.
